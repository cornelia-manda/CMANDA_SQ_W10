# Side Quest Remix: Save the Spiders - Safe Haven Edition

## Overview

This remix extends the base vertical shoot 'em up game with four new mechanics:

1. **Web Safe Zones**: Safe webs where the player is immune to owl attacks.
2. **Ant Health Collectibles**: Bugs scattered around the level that restore player health.
3. **One-Use Web Shield**: Activated via `E` or `Shift` to provide temporary invincibility.
4. **Game Timer & Enhanced HUD**: Real-time timer and indicator statuses.

## Controls

- **Move**: `W`/`A`/`S`/`D` or Arrow Keys
- **Shoot**: `Spacebar`
- **Web Shield**: `E` or `Shift` key (1 use per run)
- **Restart**: `R` key
