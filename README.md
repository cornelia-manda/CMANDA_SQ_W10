# CMANDA_SQ_W6: Side Quest #10 - Save the Spiders!!!! (Remix Edition)

## Setup and Interaction Instructions

Open the playable link on Google Chrome and click to start playing!

- **Move Character**: Use the `W`/`A`/`S`/`D` keys or the standard `Arrow Keys`.
- **Shoot/Action**: Press the `Spacebar` to fire web projectiles in the direction you are facing.
- **Web Shield**: Press `E` or `Shift` to activate a one-time protective web shield that gives invincibility for 3 seconds.
- **Restart**: Press `R` to restart after a Victory or a Game Over state screen is reached.

## Remix Changes & New Mechanics

This remix extends the base game by adding four meaningful gameplay changes and new interactive elements:

- **Web Safe Spots**: Circular safe zones positioned along the world path where owls cannot deal damage to the spider.
- **Ant Collectibles**: Ants placed throughout the map that restore 2 health points when eaten.
- **One-Use Web Shield Ability**: A special active skill that makes the player invincible to enemies and obstacles for 3 seconds.
- **Game Timer & Enhanced HUD**: Real-time gameplay timer added to the HUD, along with a web shield readiness status and safe zone indicator.
